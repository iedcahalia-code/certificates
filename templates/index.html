Bulk Certificate Generator

Create certificates in bulk using a PowerPoint template and participant Excel file.

How it works:
  • Upload a .pptx certificate template containing placeholders like {% raw %}{{student_name}}{% endraw %}.
  • Upload an Excel file with matching column names (for example: student_name).
  • Download one ZIP file containing all generated certificates and a manifest Excel file.
